# 智能食谱查找器

一个离线命令行的智能菜谱推荐系统。根据你手中现有的食材，智能匹配可制作的菜谱，支持食材同义词、替换匹配、多维度筛选排序、购物清单生成和一周推荐计划。

**主要特点**：

- 🔌 **完全离线**：无需网络，所有数据存储在本地 JSON 文件中。
- 🧠 **智能匹配**：精确匹配 + 部分匹配 + 同义词归一化 + 食材替换建议。
- 🏷️ **智能调料识别**：内置 90+ 种调料的自动识别，区分主料与调料。
- 🗂️ **丰富数据**：767 道菜谱（全部食材名、用量、制作步骤已汉化）、175 条同义词映射、26 条替代规则，覆盖 5 大区域 40+ 菜系。
- ⌨️ **命令行友好**：同时支持交互式菜单和纯命令行参数两种模式。
- 🌐 **全中文**：菜谱名称、食材、用量、制作步骤均已翻译为中文，方便中文用户使用。
- 🪶 **零依赖运行**：运行时仅使用 Python 标准库，无需安装任何第三方包。

### 数据流向

```
用户输入食材 → display.parse_ingredients_input() 解析
    → matcher: 同义词归一化（"西红柿"→"番茄"）
    → cli.run_search() 核心搜索：
        ├─ matcher.weighted_match() 逐菜谱计算匹配度
        ├─ filter_sort 筛选（时间/菜系/饮食标签）
        └─ filter_sort 排序（匹配度/时间/热量）
    → display 格式化输出结果
    → shopping 生成购物清单 & 缩放配方
```

## 使用方法

### 1. 交互式菜单模式

直接运行 `run.py`，通过菜单提示逐步操作：

```bash
python run.py
```

主菜单提供 5 个选项：

| 序号 | 功能 | 说明 |
|------|------|------|
| 1 | 输入食材查找菜谱 | 输入食材 → 允许替换 → 筛选(时间/菜系/标签) → 排序 → 购物清单/缩放 |
| 2 | 一周推荐计划 | 贪心算法推荐多道菜谱，支持合并购物清单 |
| 3 | 给菜谱评分 | 1~5 星评分，加权计算平均分 |
| 4 | 收藏夹管理 | 查看、添加、移除收藏，导出/导入 JSON |
| 5 | 退出 | — |

### 2. 命令行参数模式

通过 `--ingredients` 参数直接在命令行中执行搜索：

```bash
python run.py --ingredients "西红柿,鸡蛋" [可选参数...]
```

**支持的参数**：

| 参数 | 类型 | 说明 |
|------|------|------|
| `-i` / `--ingredients` | string | 用户拥有的食材，逗号分隔（必填） |
| `-s` / `--allow-substitution` | flag | 是否允许食材替换（默认不允许） |
| `--max-time` | int | 最大总耗时过滤（分钟） |
| `--cuisine` | list | 按菜系过滤，如 `--cuisine 中餐 川菜` |
| `--dietary` | list | 按饮食标签过滤，如 `--dietary 素食 高蛋白` |
| `--sort` | choice | 排序：`match`(匹配度) / `time`(耗时) / `calories`(热量) |
| `--top` | int | 显示前 N 条结果（默认 5） |
| `--shopping` | flag | 对最佳匹配菜谱生成购物清单 |
| `--scale` | float | 缩放倍数，配合 `--shopping` 使用 |

可用饮食标签：`荤菜` `素食` `纯素食` `高蛋白` `低卡` `低碳水` `快手` `无麸质`

## 匹配算法说明

### 加权匹配

- 菜谱中的**调料**被自动识别并排除，不计入匹配度分母
- **主料精确匹配**：用户食材与菜谱主料名称一致 → 得分 +1.0
- **主料替代匹配**：用户食材在菜谱主料的替代列表中 → 得分 +0.8
- **匹配率 = 总得分 / 主料数量**

例如：菜谱需要 "鸡蛋"（主料），用户有 "鸭蛋"（鸡蛋的替代品之一），开启替代后匹配率为 80%。

### 调料识别

系统内置 90+ 种调料词条，涵盖盐、糖、油、酱油、醋、料酒、葱姜蒜、辣椒、咖喱、香料、酱料等。调用 `is_seasoning()` 自动判断原料是否为调料。

## 数据文件格式说明

### `data/recipes.json`

菜谱主数据文件（767 道），每道菜谱的结构如下：

```json
{
  "id": "a1b2c3d4-e5f6-7890-abcd-ef1234567890",
  "name": "番茄炒鸡蛋",
  "ingredients": [
    { "name": "番茄", "quantity": "2个" },
    { "name": "鸡蛋", "quantity": "3个" },
    { "name": "盐", "quantity": "适量" },
    { "name": "食用油", "quantity": "2汤匙" }
  ],
  "steps": [
    "番茄洗净切块",
    "鸡蛋打散",
    "锅中倒油烧热，倒入蛋液炒至凝固盛出",
    "放入番茄翻炒，调味，倒入鸡蛋翻匀"
  ],
  "prep_time": 10,
  "cook_time": 8,
  "cuisine": "中餐",
  "dietary_tags": ["素食"],
  "nutrition": {
    "calories": 180.0,
    "protein": 12.0,
    "fat": 13.0,
    "carbs": 8.0
  },
  "rating": 4.5,
  "ratings_count": 10,
  "is_favorite": false
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | string (UUID) | 菜谱唯一标识 |
| `name` | string | 菜谱名称 |
| `ingredients` | list | 原料列表，每项含 `name` 和 `quantity` |
| `steps` | list[string] | 烹饪步骤 |
| `prep_time` | int | 准备时间（分钟） |
| `cook_time` | int | 烹饪时间（分钟） |
| `cuisine` | string | 菜系 |
| `dietary_tags` | list[string] | 饮食标签 |
| `nutrition` | object | 营养成分（calories/protein/fat/carbs） |
| `rating` | float | 用户加权平均评分 |
| `ratings_count` | int | 评分总人次 |
| `is_favorite` | bool | 是否收藏 |

### `data/synonyms.json`

食材同义词映射（175 条）：key 为标准名称，value 为同义变体列表。

```json
{
  "番茄": ["西红柿", "圣女果"],
  "马铃薯": ["土豆", "洋芋"],
  "香菜": ["芫荽"]
}
```

用户输入"西红柿"时，系统会自动归一化为"番茄"进行匹配。

### `data/substitutions.json`

食材替换规则（26 条）：key 为菜谱中要求的原料，value 为可接受的替代品列表。

```json
{
  "黄油": ["人造黄油", "植物油"],
  "牛奶": ["豆奶", "杏仁奶", "椰奶"],
  "鸡蛋": ["鸭蛋", "鹅蛋"],
  "面粉": ["全麦面粉", "米粉", "杏仁粉"]
}
```

启用 `--allow-substitution` 后，"鸡蛋"可被"鸭蛋"替代（匹配权重 0.8）。
